# eesyapi.py

`eesyapi.py` is a Python package for working with the Explore Education Statistics API.

The package helps users build API URLs, query datasets, and retrieve publication or dataset information using Python.

## Main features

- Build API URLs
- Query the EES API
- Retrieve dataset versions
- Convert filter types
- Work with API response data
